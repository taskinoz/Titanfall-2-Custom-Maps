# Surf Me 0.1.0

surf_me by **not_a_zombie** (bonus 1 by Xtra_Festive, bonus 2 by Malt, bonuses 3
and 4 by not_a_zombie), converted for Titanfall 2 / Northstar.
Original author page: https://gamebanana.com/mods/122524
Conversion source and AI disclosure: https://github.com/taskinoz/Titanfall-2-Custom-Maps

Install MRVN.SourceSurfMe alongside **MRVN.Surf 0.2.0 or later** (Surf 0.1.0 cancels
runs at stage transitions), then run:

    mp_gamemode surf
    map mp_source_surf_me

Five timed stages. Each stage's end teleport takes you to the next stage; a fail on
a later stage returns you to that stage's start without stopping the timer.
Skipping or going back a stage cancels the run. The boost key resets to stage 1.
The finish counts only after all four stage transitions.

Everyone in the match needs the same map version. Do not enable duplicate manual
and Thunderstore installations of this mod.

This is a converted preview. The four bonus areas are converted but have no
separate timers or leaderboard categories. Player-name filters, animated flames,
particles, overlays, normal maps and water are not reproduced. Wall tops that can
be stood on in the original can be stood on here too.

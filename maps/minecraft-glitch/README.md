# Glitch (Minecraft)

![AI generated](../../.github/badges/ai-generated.svg)

Oblivering's Minecraft recreation of Titanfall 2's Glitch, converted back into a
Titanfall 2 map for Northstar. The original human-built map is
[on Planet Minecraft](https://www.planetminecraft.com/project/glitch-titanfall-2/);
its author describes it as 55% complete and permits derivatives with credit.
This conversion was produced with AI (see [AI.md](../../AI.md)).

## Play

Install from Thunderstore with a Northstar mod manager, or download
`MRVN.MinecraftGlitch-<version>.zip` from the
[releases](https://github.com/taskinoz/Titanfall-2-Custom-Maps/releases) and extract
the `MRVN.MinecraftGlitch` folder into `Titanfall2/R2Northstar/mods`. Then, in a private
match or from the console:

```text
map mp_minecraft_glitch tdm
```

Everyone in the match needs the same version.

## What's converted

- 44,811 blocks become merged brushes at 48 units per block, with Minecraft
  1.20.6 textures, sun shadows and baked ambient light.
- Four native ziplines in place of the Minecraft iron-bar lines.
- A death pit at Z -192, wall torches with baked lights, a Minecraft-style sky
  dome and an invisible roof and walls around the build.
- Eight start and respawn sites per team under open sky, a custom loading
  screen and a block-built multiplayer menu stage.

Not converted: navmesh, Titans, AI, objective modes, redstone, plants and signs.
The world is missing a piece of terrain at one corner, which the converter fills
with grass. At the north edge a one-block strip lets pilots step off and fall.

## Files

| Path | Contents |
| --- | --- |
| `mod/MRVN.MinecraftGlitch/` | Text files of the shipped mod: `mod.json`, level script, map name strings and entity lumps |
| `source/mp_minecraft_glitch.map` | Editable MRVN-Radiant map generated by the converter |
| `source/conversion.json` | Selection bounds, anchor, block counts and omitted block types |
| `loadscreen.png` | The in-game capture used for the loading screen |
| `build.ps1` | The exact converter command for this map |
| `CHANGELOG.md` | Version history |

The release `MRVN.MinecraftGlitch-source-<version>.zip` adds the editor textures
needed to open the `.map` in MRVN-Radiant. To rebuild, see
[docs/building.md](../../docs/building.md).

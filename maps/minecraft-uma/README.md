# UMA (Minecraft)

![AI generated](../../.github/badges/ai-generated.svg)

BirthdayTrain's Minecraft recreation of Titanfall 2's UMA, converted back into a
Titanfall 2 map for Northstar. The original human-built map is
[on Planet Minecraft](https://www.planetminecraft.com/project/ru-titanfall-2-uma/);
this conversion was produced with AI (see [AI.md](../../AI.md)).

| | |
| --- | --- |

| Current version | 0.5.2 |
| Status | Preview: pilot-only, single-player and local-server tested |

## Play

Install from Thunderstore with a Northstar mod manager, or download
`MRVN.MinecraftUma-<version>.zip` from the
[releases](https://github.com/taskinoz/Titanfall-2-Custom-Maps/releases) and extract
the `MRVN.MinecraftUma` folder into `Titanfall2/R2Northstar/mods`. Then, in a private
match or from the console:

```text
map mp_minecraft_uma tdm
```

Everyone in the match needs the same version.

## What's converted

- 47,400 blocks become merged brushes at 48 units per block, with Minecraft
  1.20.6 textures, sun shadows and baked ambient light.
- 96 wall torches with baked lights in dark rooms.
- A Minecraft-style sky dome, an invisible roof and walls around the build, and
  the author's barrier blocks and glass roof as invisible clip.
- Eight start and respawn sites per team, a custom loading screen and a
  block-built multiplayer menu stage.

Not converted: navmesh, Titans, AI, objective modes, redstone and command
blocks, plants, signs and banners. Three of the eight spawn sites are in a dark
corridor.

## Files

| Path | Contents |
| --- | --- |
| `mod/MRVN.MinecraftUma/` | Text files of the shipped mod: `mod.json`, level script, map name strings and entity lumps |
| `source/mp_minecraft_uma.map` | Editable MRVN-Radiant map generated by the converter |
| `source/conversion.json` | Selection bounds, anchor, block counts and omitted block types |
| `loadscreen.png` | The in-game capture used for the loading screen |
| `build.ps1` | The exact converter command for this map |
| `CHANGELOG.md` | Version history |

The release `MRVN.MinecraftUma-source-<version>.zip` adds the editor textures
needed to open the `.map` in MRVN-Radiant. To rebuild, see
[docs/building.md](../../docs/building.md).

# Surf Beginner 0.2.1

surf_beginner, a Counter-Strike: Source surf map by an unconfirmed author,
converted for Titanfall 2 / Northstar. Original BSP source:
https://main.fastdl.me/maps/surf_beginner.bsp.bz2
Conversion source and AI disclosure: https://github.com/taskinoz/Titanfall-2-Custom-Maps

Install MRVN.SourceSurfBeginner alongside **MRVN.Surf 0.2.0 or later**, then run:

    mp_gamemode surf
    map mp_source_surf_beginner

Seven timed stages. Each stage's end teleport takes you to the next stage; a fail on
a later stage returns you to that stage's start without stopping the timer.
Skipping or going back a stage cancels the run. The boost key resets to stage 1.
The finish counts at the stage-7 end doorway.

Everyone in the match needs the same map version. Do not enable duplicate manual
and Thunderstore installations of this mod.

This is a converted preview. Seven Counter-Strike: Source materials could not be
read without a CS:S install and render plain grey. Animated effects, overlays,
normal maps and water are not reproduced. The original spawn room, secret area and
toilet end room are kept.

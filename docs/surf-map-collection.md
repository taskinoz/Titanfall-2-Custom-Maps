# Surf map collection

Requested from [Refrag's Best Surf Maps in CS2 article](https://refrag.gg/blog/best-surf-maps-in-cs2/).
Downloaded on 2026-11-09. These are the original **Source 1 counterparts**, not the
CS2 Workshop remakes. They work with the existing BSP-to-Titanfall converter.
Original files stay in MRVN-Radiant's ignored `.local/respawn/surf-collection/downloads/`.
The exact URLs, sizes, BSP versions and SHA-1/SHA-256 checksums are in
[`maps/surf-map-sources.json`](../maps/surf-map-sources.json).

| Article map | Downloaded input | Conversion status |
| --- | --- | --- |
| surf_beginner | surf_beginner.bsp | Local seven-stage preview; see its [map README](../maps/source-surf-beginner/README.md) |
| surf_me | surf_me.bsp | First local Titanfall 2 preview; see its map README |
| surf_utopia | surf_utopia_v3.bsp | Matches the existing Surf Utopia conversion |
| surf_kitsune | surf_kitsune.bsp | Downloaded and verified; not converted yet |
| surf_cyberwave | surf_cyberwave.bsp | Downloaded and verified; not converted yet |

The compressed inputs were downloaded from fastdl.me. Each decompressed BSP matches
its index's size and SHA-1 and has a valid Source BSP header. Surf Me was independently
checked against the author's GameBanana archive: the BSPs are byte-identical.

The original Surf Me is a five-stage Egyptian course with four bonus areas. This is
not a claim that it matches every change in a later CS2 remake. No new map release
has been published as part of this collection work.

# AI disclosure

The map conversions, build recipes, release tooling and documentation in this
repository were produced with AI: Anthropic's Claude (through Claude Code), with
some earlier builds by OpenAI's Codex. The
maintainer, Tristan Kennedy, chose the maps, directed the work, play-tested the
builds in Titanfall 2 and decides what is released. AI also ran most of the
in-game checks described in each map's README through an automated test harness.

The badge is a self-declaration. It is not a quality rating or a security review.

## The original, human-built maps

None of these levels were designed by AI. Each conversion starts from a map
built by people, and the originals are the place to see their work as intended:
